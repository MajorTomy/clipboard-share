# 剪切板共享 Clipboard Share

在局域网内让手机和电脑共用剪切板。电脑端运行一个 Python 小程序，手机用浏览器扫码打开网页即可，**手机无需安装任何 App**。

- 支持 Windows / macOS / Linux
- **配对一次，一直可用**：配对信息保存在电脑上，重启电脑、重启程序都不用重新扫码
- **系统托盘图标**：不占用命令行窗口，可在托盘菜单里显示二维码、开关开机自启动、退出
- **开机自启动**：在托盘菜单里勾选即可
- 支持中文等任意文字（暂不支持图片、文件）

## 使用方法

1. 电脑上安装 Python 3.8 或更新版本（Windows 可从 [python.org](https://www.python.org/downloads/) 下载，安装时勾选 “Add Python to PATH”）。
2. 启动：
   - **Windows**：双击 `start-windows.bat`
   - **macOS**：双击 `start-mac.command`

   启动脚本会自动安装托盘图标需要的 `pystray` 和 `Pillow`，然后在后台运行。
3. 第一次运行时电脑浏览器会打开二维码页面，手机连接**同一个 Wi-Fi** 后扫码。
4. 在手机上把打开的页面**加入书签**或**添加到主屏幕**，以后直接点开就能用。
5. 手机网页上：
   - **📱 → 💻 发送到电脑**：粘贴或输入文字，点“发送到电脑”，电脑上直接 Ctrl+V / ⌘V
   - **💻 → 📱 电脑剪切板**：显示电脑当前剪切板内容，点“复制到手机”

## 托盘菜单

托盘图标在 Windows 任务栏右下角（可能收在 `^` 里），macOS 在屏幕顶部菜单栏。

| 菜单项 | 作用 |
|---|---|
| 显示配对二维码 | 给新手机配对时用 |
| 开机自启动 | 勾选后，登录电脑时自动在后台启动 |
| 重新配对 | 生成新的访问码，**所有已配对的手机都要重新扫码**（手机丢失时用） |
| 退出 | 关闭程序 |

## 命令行参数

```
python clipboard_share.py [--port 端口] [--reset] [--no-tray] [--autostart on|off]
```

- `--port 9000`：换端口（默认 8765），会被记住
- `--reset`：重新配对
- `--no-tray`：不显示托盘图标，在命令行中运行（没装 pystray/Pillow 时也会自动这样运行）
- `--autostart on|off`：开启 / 关闭开机自启动

配对信息保存在：
- Windows：`%APPDATA%\ClipboardShare\config.json`
- macOS：`~/Library/Application Support/ClipboardShare/config.json`
- Linux：`~/.config/ClipboardShare/config.json`

## 注意事项

- **电脑 IP 变了怎么办**：手机书签里记的是电脑的局域网 IP。如果路由器给电脑换了 IP，书签会打不开，需要重新扫码（访问码不变）。想彻底避免，可以在路由器里给电脑设置“固定 IP / DHCP 静态分配”。
- **Windows 防火墙**：第一次运行会弹窗询问，请勾选“专用网络”并允许，否则手机连不上。
- **安全**：访问码包含在二维码链接里，没有访问码的请求会被拒绝。只在可信的局域网中使用；手机丢失时请在托盘菜单里“重新配对”。
- **手机复制/粘贴按钮**：网页是普通 http，部分手机浏览器不允许网页直接读写剪切板。此时复制会自动选中文字，长按即可复制；粘贴请长按输入框选择“粘贴”。
- **程序文件挪了位置**：开机自启动记录的是程序路径，挪动后请用新位置再启动一次，会自动更新。
- **Linux**：需要安装 `xclip`（X11）或 `wl-clipboard`（Wayland）；托盘图标需要桌面环境支持 AppIndicator。
